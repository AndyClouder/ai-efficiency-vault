# 专业内容转外行指南（Skill）

## 核心要点

- **核心痛点**：FDE 咨询团队每接一个新客户就进入陌生行业，客户发来的专业资料全是给内行看的，外行读起来处处卡壳，效率极低。本 Skill 把「外行几天内变半个内行」的流程标准化。
- **目标**：把给内行看的专业资料（行业报告、专业书籍、白皮书、专家录音/教学文字稿），转化成外行能达到「可以跟专家对话」深度的文档。不是做摘要，而是补齐认知 Gap。
- **严格两阶段**：第一阶段「理解与规划」输出五项分析后**必须停下等用户确认**，确认后才进第二阶段「写作」。未确认方向前写的任何内容都可能白费。
- **概念讲解六层（缺一不可）**：是什么 / 为什么重要 / 怎么判断 / 怎么用 / 常见错误 / 边界在哪。最容易跳过的是「常见错误」和「边界」。
- **例子展开四层**：说明什么概念 / 具体场景（没看过原资料也懂）/ 怎么体现（要有分析）/ 换种做法会怎样（要有对比）。
- **认知 Gap 四类型搭桥**：因果关系、概念对比、应用边界、逻辑跳跃。原则是内行默认脑补的推导，外行需要完整的推理桥梁。
- **阅读体验硬规则**：禁用破折号（用逗号或分句替代）；引号一律用「」；语气是「思考引导式」而非「教学式」。
- **七条常见陷阱**：跳过第一阶段直接写、概念只讲是什么不讲边界、例子只描述不分析、Gap 只标注不搭桥、术语堆砌不解释、用破折号、写成教科书。

## 原文摘要

### 适用与不适用

- **适用**：FDE 快速切入陌生行业、客户发来长篇专业资料需补课、专家录音/教学视频文字稿转化、接触新行业前突击学习。
- **不适用**：只需摘要/大纲（用普通摘要工具）、读者已是内行、资料本身就是面向外行的科普。

### 第一阶段：理解与规划（五项分析，输出后等确认）

1. **主题识别**：一句话概括核心主题 + 它要解决的根本问题。完成标准是能向不相关的人解释这个主题在干什么。
2. **知识结构梳理**：穷举核心概念，理清递进/并列/因果关系，给出按认知逻辑的展开顺序（不按资料原顺序）。完成标准是画得出概念关系图。
3. **关键例子盘点**：资料中每个案例说明什么概念。完成标准是每个例子都映射到至少一个核心概念。
4. **认知 Gap 预判**：外行会在哪卡住、有哪些「内行默认知道外行不知道」的前置知识、有哪些逻辑跳跃要搭桥。每个 Gap 标注类型（因果/对比/边界/跳跃）和搭桥方案。
5. **预期产出**：读者读完后应能做到什么，能力清单可验证（「能解释 X」而非「了解 X」）。

### 第二阶段：写作标准

- **概念讲解六层**：是什么 / 为什么重要 / 怎么判断（面对案例怎么判断做到没）/ 怎么用（具体一步步）/ 常见错误（大多数人怎么做错）/ 边界在哪（什么情况适用/不适用）。
- **例子展开四层**：说明什么概念 / 具体场景 / 怎么体现该概念（分析而非描述）/ 换一种做法会怎样（对比）。
- **「所以呢」补全**：每个概念讲完回答三问——知道后实际怎么用、怎么验证案例做到没、原资料没讲则按上下文推导。每个概念都要有一个可操作的「下一步动作」。
- **认知 Gap 搭桥（四类型）**：因果（A 为什么导致 B，中间机制）、对比（与相似概念的本质区别）、边界（适用/不适用及原因）、跳跃（补全内行脑补的简化推导链）。
- **术语处理**：核心概念术语必须解释并融入叙述（不单独列出）；非主线术语靠上下文自然理解。判断标准：去掉解释读者还能跟上吗，能跟上就不单独解释。
- **口语到书面**：「大家看这个」还原「这个」是什么、「就是那种感觉」具体描述、「你们懂的」把懂的内容写出来、重复强调保留一次。
- **视觉信息转化**：PPT/图表/板书等，判断核心信息 → 提取核心忽略装饰 → 用叙述性语言重构，不写「视频中展示了一张图」这种跳出式说明。
- **保留有价值思考过程**：「先试 A 发现不对转向 B」的试错过程要保留（展示认知演进），单纯跑题不保留。
- **结构原则**：可在不增加新事实前提下重组论述顺序；列举时先建立逻辑（为什么是这几个）→ 保持叙述感 → 总结关联（共同点是什么）。

### 验收清单（关键项）

- 第一阶段五项分析已输出且用户确认后才进第二阶段
- 每个核心概念六层全覆盖、每个案例四层全展开
- 每个概念有「所以呢」补全、认知 Gap 实际搭了桥（不止标注）
- 全文无破折号、引号用「」
- 模拟读者读一遍不在任何地方卡壳，能用自己的话解释概念、举出原文没有的新例子、判断新情况属于哪种类型、跟专业人士对话能跟上节奏并提有深度的问题
