# 类型：flowchart(流程图 / 工作流)

> 3-6 阶段按方向连接，箭头表流向。用于工作流、pipeline、步骤序列。与 architecture 的区别：flowchart 有**方向**(谁先谁后)，architecture 是**结构**(谁在上谁在下)。

## 1. 构图骨架

三种子结构，每图选一种：

### 横向流(最常见)

```
[①采集] → [②清洗] → [③计算] → [④输出]
```

### 纵向流(步骤多、每步说明长)

```
[①需求]
    ↓
[②设计]
    ↓
[③开发]
    ↓
[④测试]
```

### 蛇形流(步骤多但想省空间)

```
[①] → [②] → [③]
                  ↓
[⑥] ← [⑤] ← [④]
```

- **节点**：圆角矩形或圆形，统一形状
- **连线**：粗箭头(2.5px)，统一描边
- **方向标**：箭头是核心，必须清晰、不被遮挡
- **步骤编号**：每节点左上角 ①②③ 或 01/02/03

## 2. 节点规则

| 字段 | 内容 |
|---|---|
| 步骤号 | ①②③ 或 01/02/03 |
| 标题 | 动词开头(采集/清洗/计算)，≤4 字 |
| 说明 | 一行(≤14 字)，可选 |

> 节点用动词；不要用名词(那是 architecture 的节点)。

## 3. 分支与汇聚

流程有条件分支时：

- **判断节点**用菱形 `<polygon>` 或圆角菱形，标签"条件?"
- **分支线**带标签("是"/"否"，或具体条件值)
- **汇聚点**用小圆点或直接多条线汇入下一节点

```
        ┌─ 是 → [处理]
[判断] ─┤
        └─ 否 → [跳过]
```

## 4. 默认画布

| 步骤数 | 画布 |
|---|---|
| 3-4 步横向 | 1280×720 |
| 5-6 步横向 | 1920×720 |
| 5+ 步纵向 | 720×1280 |
| 6+ 步蛇形 | 1280×720 |

## 6. 红线

- ❌ 不画无标签的判断分支(读者不知道走哪条)
- ❌ 不画回流除非真是循环(那是 cycle 类型)
- ❌ 节点形状不统一(混用矩形圆菱形且无语义)
- ✅ 每条箭头方向明确，主流程从左到右/从上到下
