# 恢复初始化

> 把知识库安全地还原到"出厂状态"。**强制备份在前，删除在后，宁可中止不可丢数据。**

---

## 触发条件

- 用户说："重置知识库""恢复初始化""清空重来""工厂重置""回到初始状态"
- 被「新手引导」skill 在"已有内容 → 用户选择重置"分支中主动调用

---

## 工作流程

### 第 1 步：统计将处理的内容

扫描并统计，让用户对即将被处理的内容规模一目了然：

**知识内容**（5 个 PARA 目录）：
- `0_Inbox/` 下所有 .md 文件数
- `1_Projects/` 下所有 .md 文件数（**排除 `_模板/`**）
- `2_Areas/` 下所有 .md 文件数
- `3_Resources/` 下所有 .md 文件数
- `4_Archives/` 下所有 .md 文件数

**记忆文件**（5 个）：
- `0_系统配置/SOUL.md`
- `0_系统配置/USER.md`
- `0_系统配置/MEMORY.md`
- `0_系统配置/PREFERENCE.md`
- `0_系统配置/INVENTORY.md`

输出清单示例：
```
📋 将被备份+清空的内容：

知识笔记：N 篇
  · 0_Inbox/         x 篇
  · 1_Projects/      x 篇（保留 _模板/）
  · 2_Areas/         x 篇
  · 3_Resources/     x 篇
  · 4_Archives/      x 篇

记忆文件：5 个（将重置为初始模板，不删除）
  · SOUL.md / USER.md / MEMORY.md / PREFERENCE.md / INVENTORY.md
```

### 第 2 步：备份到桌面（强制，不可跳过）

**备份目标路径**（动态获取用户桌面，不硬编码）：
```
$env:USERPROFILE\Desktop\AI效能知识库_备份_{YYYY-MM-DD-HHMMSS}.zip
```

**备份范围**：整个 vault，但排除 `.git/`（如存在）

**执行命令**（PowerShell）：
```powershell
$ts = Get-Date -Format "yyyy-MM-dd-HHmmss"
$dst = "$env:USERPROFILE\Desktop\AI效能知识库_备份_$ts.zip"
Compress-Archive -Path "$env:USERPROFILE\Desktop\AI效能知识库\*" -DestinationPath $dst -Force
Write-Output "BACKUP_OK:$dst"
```

执行时提示用户："备份进行中，请稍候……"

**失败处理（关键）**：
- 如果命令未输出 `BACKUP_OK:` 或抛错 → **立刻终止整个重置流程**
- 告知用户失败原因（权限不足/磁盘满/路径含特殊字符等）
- **不做任何删除操作**——宁可保守，绝不丢数据
- 让用户排查后再重试

### 第 3 步：二次确认

备份成功后，输出确认信息：

```
✓ 备份已完成
   位置：C:\Users\xxx\Desktop\AI效能知识库_备份_2026-06-22-153000.zip
   大小：x.x MB

⚠ 即将执行不可撤销的清空操作：
   · 删除 N 篇知识笔记
   · 重置 5 个记忆文件为初始模板（含 SOUL.md 人格内核，你定义的 AI 性格会被清回默认）
   · 保留所有 skill、系统配置、项目模板

确认清空？请明确回复"确认清空"或"重置"才会执行。
（回复其他任何内容都会中止，备份会保留）
```

**必须等用户明确回答**："确认清空" / "重置" / "确认" 才执行第 4 步。
- 用户犹豫、问问题、说"等等" → 暂停解答，不执行
- 用户说"算了" / "取消" → 中止流程，**备份保留**（用户可事后手动删）
- 用户回答模糊（"嗯"/"好"）→ 再问一次明确确认

### 第 4 步：执行重置

#### 4.1 清空知识内容（删除文件，保留目录骨架）

用 Bash 执行，**严格按白名单**：

```bash
cd "C:/Users/114643/Desktop/AI效能知识库"

# 清空 5 个 PARA 目录的内容（保留目录本身）
# 0_Inbox/ - 全清
find 0_Inbox -mindepth 1 -delete

# 1_Projects/ - 清空但保留 _模板/
find 1_Projects -mindepth 1 ! -path "1_Projects/_模板*" -delete

# 2_Areas/ 3_Resources/ 4_Archives/ - 全清
find 2_Areas -mindepth 1 -delete
find 3_Resources -mindepth 1 -delete
find 4_Archives -mindepth 1 -delete
```

> ⚠️ 执行前先 `ls 1_Projects/_模板/` 确认模板文件还在；执行后再 `ls` 一次验证未被误删。

#### 4.2 重置记忆文件（覆盖为初始模板状态）

**SOUL.md** → 重置为以下内容（人格回默认值，保留章节结构）：

## 注意事项

1. **备份是硬性前置**——没备份成功就不许删，宁可流程中止
2. **二次确认不能用模糊回答糊弄过去**——必须明确"确认清空"或同等意图
3. **删除前最后再 Read 一遍 `1_Projects/_模板/项目模板.md`**，确认模板存在；删除后再 Read 一次验证未误删
4. **备份 zip 保留在桌面**——即使用户事后反悔，也能从 zip 恢复
5. **本 skill 不负责重新初始化 USER.md 的真实内容**——只清空到模板状态；让用户重新填写的活儿归「新手引导」skill
6. **全程中文输出**，亲切但严肃（这是 destructive 操作，不能太轻佻）
7. **不依赖外部脚本**——只用 PowerShell（备份）+ Bash（删除）+ Write/Edit（重置模板）

---

## 与其他 skill 的协作

| 关联 skill | 衔接方式 |
|------------|----------|
| **新手引导** | 新手引导检测到"已有内容+用户选重置"时，调用本 skill；本 skill 跑完后回到新手引导继续流程 |
| **知识仪表盘** | 本 skill 重置后会在 DASHBOARD.md 留"待重算"标记，下次仪表盘 skill 会重新生成 |
| **知识清理** | 本 skill 是"全量清理+重置"，比知识清理更彻底；知识清理是"分级建议+人工确认" |
