# FarAI 品牌视觉规范(FarAI Brand Specification)

> 法本信息 FarAI 人工智能解决方案的视觉规范。本文件是所有 FarAI 风格 PPT 的配色/字体/字号/版式唯一真身,spec_lock.md 的所有数值必须来自本文件。
>
> 来源:从法本 FarAI 解决方案 PDF + 智能投标 PPTX 实测提炼,并在高力国际售前 PPT 项目中验证通过。

### 1.3 配色使用规则

- **60-30-10 原则**:主色(白底/浅蓝灰)60% + 品牌蓝(深蓝/亮蓝)30% + 强调色(绿/橙/青)10%
- **每页不超过 4 色**:白底 + 深蓝 + 1-2 个强调色;多类别用蓝绿橙青四色区分,不可再加
- **文字对比度**:正文 `#25364A` 在白底上对比度 ≥ 4.5:1;深色页用 `#FFFFFF` / `#B8C7E0`
- **痛点用橙**(`#F59E0B`)、**价值用绿**(`#0E9F6E`)、**品牌用蓝**(`#0052A6`/`#246BFE`)—— 颜色有语义,不可随意混用

## 二、字号 Ramp(基于 body=18px)

> 所有字号是 body(18px)的倍数。售前方案信息密度较高,选 18px 而非 24px。

| 角色 | 比例 | px 值 | 字重 | 用途 |
|------|------|-------|------|------|
| cover_title | 3.1x | **56** | Bold | 封面主标题 |
| chapter_number | — | **220** | Bold | 章节封面巨型半透明数字(装饰,非阅读) |
| chapter_title | 2.2x | **40** | Bold | 章节封面标题 |
| page_title | 1.67x | **30** | Bold | 内容页主标题 |
| hero_number | 1.78x | **32** | Bold | 关键数据/量化指标大字 |
| subtitle | 1.33x | **24** | SemiBold | 副标题/卡片标题 |
| **body** | **1x** | **18** | Regular | **正文基准** |
| annotation | 0.78x | **14** | Regular | 注释/卡片内说明 |
| page_number | 0.61x | **11** | Regular | 页脚页码/版权 |

### 字号使用规则

- **hero_number** 用于价值页的大数字(如"50%+"),借 cover_title 区间制造视觉重音
- **chapter_number** 是装饰性巨型数字,`fill-opacity="0.22"` 半透明,放章节封面左侧背景
- 卡片标题用 subtitle(24px Bold),卡片正文用 body(18px)或 annotation(14px)
- 页脚统一 page_number(11px),左下"©法本信息版权所有" + 右下页码

## 三、字体与图标

### 3.1 字体(concord 同族)

| 角色 | 字体栈 | 说明 |
|------|--------|------|
| 所有角色 | `"Microsoft YaHei", Arial, sans-serif` | 微软雅黑(中文)+ Arial(英文/数字),全篇同族 |

**层级靠字重拉开**:Bold(标题)/ SemiBold(副标题)/ Regular(正文)。不混用其他字体族。

**PPT-safe 保障**:微软雅黑是 Windows 预装字体, Arial 是跨平台预装,无需嵌入,PPTX 打开不会降级为 Calibri。

### 3.2 图标库

- **库**:`tabler-outline`(线框、专业、企业感)
- **stroke-width**:2(全局统一)
- **用法**:SVG placeholder `<use data-icon="tabler-outline/<name>" x="" y="" width="" height="" fill="#HEX" stroke-width="2"/>`
- **填色规则**:始终用 `fill="#HEX"`,**绝不**用 `stroke` 或 `fill="none"`(即使是线框库)

## 四、版式范式(4 种)

### 4.1 封面页

```
┌─────────────────────────────────────────┐
│ [深蓝渐变背景 + 径向装饰光晕]              │
│ 🧠 法本信息 · FarAI  (左上品牌标识)        │
│                                         │
│ ── (左侧色块装饰条)                       │
│ FarAI × COLLIERS (小字副标)              │
│ 商业地产 AI 智能化 (56px 大标题)           │
│ 解决方案 (56px 渐变大标题)                 │
│ 副标说明 (20px)                           │
│                                         │
│ ── 深圳市法本信息技术股份有限公司 (底部)    │
└─────────────────────────────────────────┘
```
**关键元素**:深蓝渐变背景(`#0A2A5E`→`#0E367A`→`#17365D`)+ 径向装饰光晕(`#246BFE` 20% 透明)+ 左侧色块条 + 大标题(56px 白)+ 品牌标识(左上)。

### 4.2 章节封面页

```
┌─────────────────────────────────────────┐
│ [深蓝渐变背景]                            │
│                                         │
│ 01 (220px, #246BFE, 22% 透明度,装饰)      │
│                                         │
│ ── CHAPTER 01 (20px, letter-spacing 3)   │
│ 客户理解与价值主张 (40px 白)               │
│ 副标说明 (20px 浅蓝灰)                    │
│                                         │
│ ── 底部标识                              │
└─────────────────────────────────────────┘
```
**关键元素**:巨型半透明章节号(220px,`fill-opacity="0.22"`)+ CHAPTER N 小标 + 章节标题(40px)+ 深蓝渐变背景。

### 4.3 内容页(卡片网格)

```
┌─────────────────────────────────────────┐
│ 01 客户理解 (14px 蓝小标)                 │
│ 页面主标题 (30px 深蓝粗体)                 │
│ 副标说明 (16px 灰)                        │
│ ─────────────────────────              │
│ ┌────────┐ ┌────────┐ ┌────────┐        │
│ │ 图标   │ │ 图标   │ │ 图标   │        │
│ │ 标题   │ │ 标题   │ │ 标题   │        │
│ │ 正文   │ │ 正文   │ │ 正文   │        │
│ └────────┘ └────────┘ └────────┘        │
│ ─────────────────────────              │
│ ©法本信息版权所有              04        │
└─────────────────────────────────────────┘
```
**关键元素**:
- 顶部:章节小标签(14px 蓝,letter-spacing 2)+ 主标题(30px 深蓝 Bold)+ 副标(16px 灰)
- 主体:卡片网格(2×2 / 三列 / 四列),卡片 `rx="12"` 圆角,`fill="#F4F7FC"` 浅蓝灰底,顶部色块条(`#246BFE`/`#0052A6`/`#0E9F6E`/`#F59E0B` 区分)
- 底部:页脚(11px 灰),左下版权 + 右下页码

**卡片变体**:
- 痛点卡片:左侧 4px 橙色竖条 + 圆形图标徽章 + 标题 + 正文
- 能力卡片:顶部色块条 + 图标 + 标题 + 正文 + 底部药丸标签(pill tag)
- 价值卡片:大数字(hero_number 32px)+ 说明文字

### 4.4 流程/闭环页

```
┌─────────────────────────────────────────┐
│ 标题 + 副标                               │
│ ┌────┐→┌────┐→┌────┐→┌────┐→┌────┐      │
│ │图标│ │图标│ │图标│ │图标│ │图标│      │
│ │文字│ │文字│ │文字│ │文字│ │文字│      │
│ └────┘ └────┘ └────┘ └────┘ └────┘      │
│           ↑─────────虚线回流─────────┘    │
│ 复盘结论回流说明                           │
└─────────────────────────────────────────┘
```
**关键元素**:
- 等宽圆角节点(`rx="12"` 或圆形),节点内图标(40px 白)+ 文字(14px 白)
- 节点用 `<marker id="arrow">` 三角箭头串联(`<line marker-end="url(#arrow)"/>`)
- 闭环用虚线 `<path stroke-dasharray="6 4"/>` + 浅色箭头回流
- 节点颜色:主流程用 `#246BFE`/`#0052A6` 交替,终点用 `#0E9F6E`(完成色)

## 五、渐变定义(SVG defs)

直接复制到每个 SVG 的 `<defs>` 中使用:

```xml
<!-- 1. 封面/标题渐变(品牌蓝) -->
<linearGradient id="coverBg" x1="0%" y1="0%" x2="100%" y2="100%">
  <stop offset="0%" stop-color="#0A2A5E"/>
  <stop offset="60%" stop-color="#0E367A"/>
  <stop offset="100%" stop-color="#17365D"/>
</linearGradient>

<!-- 2. 标题强调渐变(亮蓝) -->
<linearGradient id="accentLine" x1="0%" y1="0%" x2="100%" y2="0%">
  <stop offset="0%" stop-color="#246BFE"/>
  <stop offset="100%" stop-color="#518FEC"/>
</linearGradient>

<!-- 3. 章节封面背景渐变(深蓝) -->
<linearGradient id="chapterBg" x1="0%" y1="0%" x2="100%" y2="100%">
  <stop offset="0%" stop-color="#0A2A5E"/>
  <stop offset="100%" stop-color="#17365D"/>
</linearGradient>

<!-- 4. 径向装饰光晕(背景点缀) -->
<radialGradient id="bgDecor" cx="85%" cy="15%" r="50%">
  <stop offset="0%" stop-color="#246BFE" stop-opacity="0.22"/>
  <stop offset="100%" stop-color="#246BFE" stop-opacity="0"/>
</radialGradient>
```

## 六、风格依据(为什么是这套)

| 维度 | 锁定值 | 理由 |
|------|--------|------|
| **mode** | `pyramid`(结论先行) | 售前决策支持场景标配:结论→论据→数据,每页一个核心信息,高管能 30 秒抓重点 |
| **visual_style** | `soft-rounded`(圆角卡片) | 企业产品风,亲和专业;卡片 `rx="12"` 圆角温和,符合法本 FarAI 参考材料的白底卡片网格观感 |
| **画布** | 1280×720(16:9) | 标准汇报场景,投影/屏幕兼容性最佳 |
| **body 字号** | 18px | 售前方案信息密度高(每页 4-8 个要点),18px 比 24px 容纳更多内容且仍可读 |
| **字体族** | 微软雅黑(不混用) | 与 FarAI 参考材料一致;concord 同族靠字重拉层级,PPT-safe 零降级风险 |
| **图标库** | tabler-outline(stroke 2) | 线框专业感,配企业级方案调性;stroke 2 在投影上清晰可读 |
