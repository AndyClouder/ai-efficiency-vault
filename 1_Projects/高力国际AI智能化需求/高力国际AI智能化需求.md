# 高力国际 AI 智能化需求（售前）

> **客户定位**：高力国际（Colliers）体系内企业 —— 全球商业地产"五大行"之一。
> **核心业务**：商业地产全生命周期服务（咨询策划、招商租赁、买卖交易、资产评估、工程项目管理、物业及资产管理），服务地产开发商/楼宇园区业主/投资机构/政府/大型企业。

## 项目目标

为高力国际规划一套覆盖「招聘—商机—投标—销售」四大业务链路、并能打通"信息发现—商机识别—客户归并—决策链分析—销售跟进—投标支持—结果复盘"完整闭环的 AI 智能化方案，形成可对外汇报的售前材料，支撑商务推进。

## 客户业务背景

- **行业定位**：全球商业地产"五大行"之一，非传统物业公司
- **业务特点**：管理项目多、项目信息分散、销售跟进周期长、客户决策链复杂、一线物业服务人员招聘需求量大
- **服务对象**：地产开发商、楼宇和园区业主、投资机构、政府部门、大型企业

## 整体业务痛点（4 条）

1. 基层岗位招聘量大、流动性高，58 同城等平台重复发布/筛选/邀约负担重
2. 商业地产商机分散在政府网站/招投标平台/短视频/招聘平台等多渠道，人工收集易遗漏
3. 同一楼宇/园区/企业被多名销售分散跟进，难以识别为同一客户、难以还原决策链
4. 销售录音数量大，依赖人工回听，话术规范性/客户意向/商机识别效率低

## 四大需求方向（结构化整合）

### 1. 智能招聘（基层岗位）
**对象/渠道**：保安、保洁、物业服务岗位；58 同城等招聘平台。
**功能**：岗位批量发布 → 候选人信息收集 → 基础条件筛选 → 自动沟通邀约 → 面试安排 → 招聘过程跟踪。
**核心痛点**：量大流频繁 / 简历质量参差 / 多平台重复 / 失联爽约到岗率低 / 历史候选人未沉淀复用。

### 2. 智能信息收集与商机识别（面向市场部）
**信息源**：政府网站、公共资源交易平台、招投标平台、抖音等短视频平台、招聘平台、其他公开渠道。
**关注商机类型**：新建写字楼/商业综合体/产业园区、城市更新及大型基建、楼宇出售/大宗交易/产权转让、楼宇易主/资产收购/股权变更、新项目招商及物业运营招标、企业搬迁扩建新办公场所等潜在线索。
**解析能力**：对网页/文档/图片/音视频等非结构化内容采集解析。
**提取字段**：项目名称、项目地址、建筑面积、建设进度、业主单位、投资方、交易方、联系人、预算、招标时间。
**输出**：按规则判商机价值 → 结构化线索 → 自动推送对应商务 → 记录来源/跟进/转化。
**核心痛点**：来源多而散 / 视频图片长文本提取难 / 重复缺去重 / 缺价值判断与优先级 / 难快速分配销售。

### 3. 智能投标 + 客户关系分析（商业地产特色重头）⭐
**投标部分**：招标文件解析 → 资格条件识别 → 评分项拆解 → 历史材料匹配 → 标书辅助生成 → 风险检查 → 投标材料完整性校验。
**客户主体识别（关键增量）**：结合企业名/项目名/楼宇地址/联系人/沟通记录/股权关系，判断不同销售跟进的线索是否同一客户/同一项目，形成**统一客户视图**。
**决策链梳理**：识别最终决策人 / 业务需求提出人 / 采购招标负责人 / 项目使用部门 / 技术方案评估人 / 业主方投资方运营方物业方 / 联系人关系与影响力 / 各销售掌握信息与跟进情况。
**核心痛点**：同一客户重复跟进 / 名称不统一 / 信息分散在个人记录与录音 / 决策链关键人物不清 / 历史标书难复用 / 招标文件人工拆解易漏。

### 4. 智能营销与销售录音分析
**处理**：销售电话/会议录音 → 语音转文字 → 按规则智能分析筛选。
**分析维度**：客户需求与关注点提取 / 楼宇出售易主招商物业更换等商机识别 / 意向强弱判断 / 预算时间竞争对手决策人提取 / 话术使用分析 / 关键问题是否问全 / 沟通质量评分 / 风险词与承诺性不规范表述识别 / 优秀话术沉淀与案例推荐 / 自动生成纪要与跟进建议。
**联动**：据录音自动关联客户/项目/联系人/销售，把信息补入客户档案与决策链。
**核心痛点**：录音量大无法逐条回听 / 缺统一沟通质量评价标准 / 真实需求与商机易被忽略 / 优秀经验难沉淀复制 / 录音客户项目跟进任务未关联。

## 整体建设目标（客户原话）

形成 **"信息发现—商机识别—客户归并—决策链分析—销售跟进—投标支持—结果复盘"** 的完整业务闭环。

**技术方案重点考虑**：多平台数据接入、音视频内容解析、客户主体识别、重复信息合并、人物关系分析、商机评分、录音分析，以及与客户现有 CRM、招聘和投标系统的集成能力。
