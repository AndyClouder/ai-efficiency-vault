# AI 效能知识库

基于 Obsidian Vault + AI Agent 的个人知识管理系统。你只需要把知识丢进来，AI 帮你自动整理、分类、关联、清理。

## 特性

- **PARA 分类体系** — Projects / Areas / Resources / Archives 四级结构，AI 自动归类
- **AI 驱动** — 7 个 Skill 覆盖知识全生命周期：入库、分类、关联、清理、仪表盘
- **零门槛** — 支持文字、URL、粘贴内容任意输入格式
- **双引擎兼容** — 同时支持 Claude Code 和 Codex

## 目录结构

```
0_Inbox/           ← 新知识落点
1_Projects/        ← 有截止日期的项目
2_Areas/           ← 持续关注的领域
3_Resources/       ← 参考资料
4_Archives/        ← 归档
0_系统配置/         ← 系统配置和记忆
```

## 快速上手

| 你说 | AI 做 |
|------|------|
| "帮我上手" | 新用户引导：检测状态、填写身份、演示能力 |
| "记一下 xxx" | 把内容结构化存入 Inbox |
| "整理一下" | 扫描 Inbox，逐条提出 PARA 分类建议 |
| "找关联" | 发现语义关联，添加 Wiki Link |
| "清理一下" | 检测过期、重复、低质量内容 |
| "看下状态" | 生成知识库仪表盘 |

## 记忆系统

AI 在协作中自动学习你的偏好，持续更新以下文件：

| 文件 | 用途 |
|------|------|
| `SOUL.md` | AI 的性格内核（用户定义） |
| `USER.md` | 你的档案（AI 自动维护） |
| `MEMORY.md` | 长期记忆（AI 自动维护） |
| `PREFERENCE.md` | 知识偏好（AI 自动维护） |

## 使用

在知识库目录下打开 Claude Code 或 Codex，直接用自然语言交互即可。
