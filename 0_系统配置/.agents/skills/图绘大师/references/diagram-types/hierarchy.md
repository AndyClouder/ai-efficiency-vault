# 类型：hierarchy(层级树 / 组织结构)

> 树状结构：根在顶/左，逐层展开。用于组织结构、分类树、上下级关系、族谱。与 architecture 的区别：hierarchy 是**严格树形**(一对多分支)，architecture 是**分层平铺**(层内并列，层间不强调父子)。

## 1. 构图骨架

### 自顶向下(组织结构最常见)

```
              [CEO]
             ╱  │  ╲
        [VP1] [VP2] [VP3]
         ╱╲          │
     [M1][M2]      [M3]
```

### 自左向右(分类树/知识树)

```
[根] ── [子1] ── [孙1.1]
     ╲
      [子2] ── [孙2.1]
            ╲
             [孙2.2]
```

- **节点**：方框/圆角矩形，同层同形同大
- **连线**：直线或正交折线(L 形接头)
- **层级**：深度 2-4 层最舒适；超过 4 层考虑折叠或拆图

## 2. 节点规则

| 层级 | 字号 | 视觉权重 |
|---|---|---|
| 根 | 18-20px | 最重(主色实心) |
| 中层 | 15-16px | 中(主色描边 + 白底) |
| 叶 | 13-14px | 轻(浅色底或纯文字) |

同层节点等大；父节点视觉权重大于子节点。

## 3. 连线规则

- **父子连线**：直线或正交折线，1.5-2px
- **不用箭头**(hierarchy 是包含/隶属关系，无流向)
- **接头**：用正交折线时，子线从父节点底部中点垂直向下再水平分叉到各子节点(组织结构图标准画法)

```
[父]
 │
 ├──────┬──────┐
[子1]  [子2]  [子3]
```

## 4. 默认画布

| 结构 | 画布 |
|---|---|
| 自顶向下，3 层 | 1280×720 |
| 自顶向下，4 层 | 1280×900 |
| 自左向右，深树 | 1920×720 |

## 6. 红线

- ❌ 不用箭头(hierarchy 是结构不是流程)
- ❌ 同层节点大小不一(除非刻意强调某个)
- ❌ 深度超过 4-5 层(考虑折叠)
- ✅ 子节点在父节点正下方(或正右方)，对齐整齐
