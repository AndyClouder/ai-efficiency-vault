# 类型：framework(框架图 / 中心辐射)

> 中心节点 + 3-6 卫星节点辐射。用于方法论、模型、中心概念 + 围绕它的要素。与 mindmap 的区别：framework 是**对称辐射**(卫星均匀分布，通常同形同大)，mindmap 是**自由发散**(分支不对称)。

## 1. 构图骨架

三种子结构，每图选一种：

### 子结构 1：中心 + 卫星(最常见)

```
        ◯
         ╲
   ◯ ──── ◆ ──── ◯
         ╱
        ◯
```

中心节点(◆)在正中，4-6 个卫星(◯)等角度分布，细线连接。

### 子结构 2：矩阵(2×2 / 3×3)

```
┌──────┬──────┐
│      │      │
├──────┼──────┤
│      │      │
└──────┴──────┘
```

等大网格，每格一个概念。(用于矩阵类型时见 `matrix.md`)

### 子结构 3：分层堆叠

```
╔══════════╗
║  层 3    ║
╠══════════╣
║  层 2    ║
╠══════════╣
║  层 1    ║
╚══════════╝
```

(用于 architecture 类型时见 `architecture.md`)

## 2. 节点规则(子结构 1)

| 角色 | 形状 | 字号 |
|---|---|---|
| 中心 | 圆/圆角方/菱形/六边形，较大 | 20-24px |
| 卫星 | 同形同大(与中心同形状族，尺寸略小) | 14-16px |

- 卫星**视觉一致**：同形状、同尺寸、同配色
- 连线**细而统一**：同粗细、同颜色，1.5-2px
- 卫星**对称分布**(上/下/左/右，或 6 等分角度)

## 3. 默认画布

1080×1080(1:1)最舒适。中心 + 4 卫星用方形画布对称感最好。

## 4. 参考模板

`templates/charts/hub_spoke.svg` —— 中心节点 + 周围卫星辐射，连接线统一。

## 5. 红线

- ❌ 卫星形状/大小/颜色不一(破坏"框架"的统一感)
- ❌ 卫星分布不对称且无刻意强调(意外的不平衡)
- ❌ 连线粗细不一
- ✅ 中心节点明显大于卫星，视觉权重最高
- ✅ 若要强调某卫星，用强调色细环(刻意的不对称)
