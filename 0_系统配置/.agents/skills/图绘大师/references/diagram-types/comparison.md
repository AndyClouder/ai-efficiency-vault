# 类型：comparison(对比 / 前后)

> 左右/上下对称分栏。用于前后对比、优劣对比、A/B 对比、方案比选。与 matrix 的区别：comparison 是**两栏并列**(对称结构，强调"这两个东西的差异")，matrix 是**多格网格**(强调多维度交叉分析)。

## 1. 构图骨架

### 左右对比(最常见)

```
┌──────────────┬──────────────┐
│   改造前      │   改造后      │
│  (Before)    │   (After)    │
├──────────────┼──────────────┤
│ • 单体架构    │ • 微服务      │
│ • 手动部署    │ • CI/CD      │
│ • QPS 1千    │ • QPS 10万   │
└──────────────┴──────────────┘
```

### 优劣对比(Pros & Cons)

```
┌──────────────┬──────────────┐
│   ✓ 优势      │   ✗ 劣势      │
├──────────────┼──────────────┤
│ • 优点1       │ • 缺点1       │
│ • 优点2       │ • 缺点2       │
└──────────────┴──────────────┘
```

### 上下对比(移动端/竖版)

```
┌──────────────────┐
│   方案 A          │
├──────────────────┤
│   方案 B          │
└──────────────────┘
```

## 2. 分栏规则

- **两栏等宽**，中间一条分隔线(实线或虚线)
- **栏头**：每栏顶部一个标题卡片(改造前/改造后，或 ✓/✗)，用对比色(前=灰/红，后=主色/绿)
- **内容**：左右逐项对应(同样的维度对比)，或各自列举

## 3. 对应项对比(推荐)

最强的对比是**逐项对应**——左右栏同一行对比同一维度：

```
┌──────────────┬──────────────┐
│   改造前      │   改造后      │
├──────────────┼──────────────┤
│ 架构: 单体    │ 架构: 微服务  │  ← 同一行对比"架构"
│ 部署: 手动    │ 部署: CI/CD  │  ← 同一行对比"部署"
│ QPS: 1千      │ QPS: 10万    │  ← 同一行对比"性能"
└──────────────┴──────────────┘
```

用浅色行分隔线让对应关系一目了然。

## 4. 视觉强调

- **"后/优"方**用主色或强调色(视觉权重高)
- **"前/劣"方**用中性灰或弱色
- 箭头或 ✓/✗ 图标强化对比语义

## 5. 默认画布

1280×720(16:9)。两栏各约 600px 宽，中间分隔。

## 6. 参考模板

- `templates/charts/comparison_columns.svg` —— 左右两栏对应对比
- `templates/charts/pros_cons_chart.svg` —— 优势/劣势两栏

## 7. 红线

- ❌ 两栏不等宽(破坏对称)
- ❌ 无栏头(读者不知道左右各代表什么)
- ❌ 对比维度不一致(左栏讲架构，右栏讲性能，无法对应)
- ✅ 两栏视觉权重区分(后/优方更突出)
- ✅ 逐项对应时左右同行对比同一维度

## 附：鱼骨图(fishbone)变体

源材料是因果分析(问题 + 多类原因)时，用鱼骨图。结构：右侧鱼头(问题) + 主骨干 + 上下斜出的分类刺(每类多个原因)。

参考模板：`templates/charts/fishbone_diagram.svg`。构图规则：
- 鱼头(问题)在右侧，方框
- 主骨干：水平粗线指向鱼头
- 分类刺：从骨干上下斜出 3-6 条，每条代表一类原因(人/机/料/法/环/测)
- 小刺：每条分类刺上再分出具体原因
