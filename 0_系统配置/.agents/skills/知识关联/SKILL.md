# 知识关联

## 触发条件

- 用户说"找关联""还有什么相关的""帮我连接"
- 用户说"这篇和哪些相关"
- 知识入库后用户确认分类后，自动触发一次关联检查
- 用户可请求全库扫描："扫描全库关联"

## 工作流程

### 第一步：确定扫描范围

- 默认：扫描刚入库/刚分类的笔记
- 用户指定："扫描全库"或"扫描 `2_Areas/` 目录"

### 第二步：语义匹配

- 基于标题关键词、标签、正文核心概念的语义相似度进行匹配
- 匹配后为每对关联笔记生成关联建议

### 第三步：添加关联链接

对每对关联笔记，在双方笔记末尾的「相关笔记」小节追加 Wiki Link：

```
## 相关笔记

- [[另一篇笔记的标题]] <!-- 关联原因：共同涉及XXX主题 -->
```

规则：
- 如果已有「相关笔记」小节，追加到末尾
- 如果没有，在笔记末尾创建该小节
- 关联原因用 HTML 注释标注（不干扰阅读，保留溯源）

### 第四步：输出关联报告

```
🔗 关联扫描报告

扫描范围：新增笔记 × 全库
发现关联：N 对

| 笔记A | 笔记B | 关联原因 |
|-------|-------|----------|
| xxx.md | yyy.md | 共同涉及产品定价策略 |
| ... | ... | ... |

已添加双向 Wiki Link ✓
```

## 注意事项

- 仅追加链接，绝不修改笔记正文
- 关联置信度低时标注 `<!-- 关联原因：待确认 -->`
- 同一篇笔记不和自己关联
- 已存在的关联不重复添加
- 不要过度关联：单篇笔记关联数 ≤ 5 对
