# 知识入库

## 触发条件

- 用户说"记一下""存一条""入库""保存这个"
- 用户直接粘贴长文本（>200字）或 URL
- 用户说"把这个网页存下来""记录一下这个"

## 工作流程

### 第一步：接收输入

识别用户提供的知识来源类型：
- **URL**：网页链接，用 Web Fetch 获取内容
- **粘贴文本**：用户直接粘贴的纯文本或 Markdown
- **文件路径**：本地文件路径，读取文件内容

### 第二步：提取核心信息

从原始内容中提取：
- **标题**：自动生成一个简洁准确的中文标题（10-20字）
- **来源**：URL 或文件名
- **日期**：当前日期
- **核心内容**：保留原文关键信息，去除广告、导航、页脚等噪音
- **关键标签**：提取 3-5 个核心关键词作为标签

### 第三步：生成结构化笔记

按照以下模板写入 `0_Inbox/`：

```
---
date: YYYY-MM-DD
source: 原始来源URL或文件名
tags: [标签1, 标签2, 标签3]
status: inbox
---

# 标题

## 核心要点

- 要点1
- 要点2
- 要点3

## 原文摘要

（保留原文关键信息的结构化摘要）

## 来源

- 原文链接/文件路径
- 保存日期：YYYY-MM-DD
```

### 第四步：告知用户

入库完成后告知用户：
- 文件已保存到 `0_Inbox/文件名.md`
- 提示："需要我帮你分类到对应的 PARA 目录吗？"

## 注意事项

- 不要对内容做价值判断，什么都存
- 标题要能让人一周后看到还能想起这是什么
- 标签用中文，3-5个，不要太泛（如"AI"太泛，用"AI效能"更好）
- 如果用户连续粘贴多条内容，每条单独存一个文件
