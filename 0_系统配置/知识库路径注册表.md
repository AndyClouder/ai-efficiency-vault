# 知识库路径注册表

> **使用说明**：把下方每个路径换成你自己知识库中对应文件的路径即可。
> 路径格式：从 vault 根目录出发的相对路径，不加开头斜杠。

## 系统配置

| 标识符 | 当前路径 | 说明 |
|--------|----------|------|
| `DASHBOARD` | `0_系统配置/DASHBOARD.md` | 知识库仪表盘（由「知识体检」维护） |
| `INDEX` | `0_系统配置/INDEX.md` | 内容目录：每页一行链接+摘要，查询先读它 |
| `LOG` | `0_系统配置/LOG.md` | 只追加时间线日志，统一前缀可 grep |
| `CLAUDE_CONFIG` | `0_系统配置/CLAUDE.md` | Claude Code 系统指令 |
| `CODEX_CONFIG` | `0_系统配置/AGENTS.md` | Codex 系统指令 |
| `CLAUDE_SKILLS_SOURCE` | `0_系统配置/.claude/skills/` | Claude Code Skills 配置源（同步基准） |
| `CODEX_SKILLS_SOURCE` | `0_系统配置/.agents/skills/` | Codex Skills 配置源（同步基准） |
| `CLAUDE_SKILLS_RUNTIME` | `.claude/skills/` | Claude Code 运行时实际加载目录 |
| `CODEX_SKILLS_RUNTIME` | `.agents/skills/` | Codex 运行时实际加载目录 |

> ⚠️ **Skill 三处镜像**：源目录（`0_系统配置/` 下）是同步基准，运行时目录（根目录的 `.claude/` `.agents/`）是各 Agent 实际加载的工作副本。修改 skill 时四处必须全部同步（两个源 + 两个运行时副本），详见 `CLAUDE.md` / `AGENTS.md` 的"Skill 三处镜像同步规则"小节。

## 给用户的定制说明

1. **必改项**：`SOUL`、`USER_PROFILE` — 这是你个人身份和 AI 性格的核心
2. **可选改**：PARA 目录的子结构可根据你的实际职业调整
3. **建议保留**：Skills 目录结构、记忆文件的维护规则
4. **路径格式**：只填从 vault 根目录开始的相对路径，不加 `/` 开头，不加 `C:\...` 绝对路径
