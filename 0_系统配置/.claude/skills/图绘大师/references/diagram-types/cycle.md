# 类型：cycle(循环 / 闭环)

> 闭环，3-6 步箭头回到起点。用于 PDCA、飞轮、持续改进、设计思维等循环过程。与 flowchart 的区别：cycle 的最后一步**回到第一步**，形成闭环；flowchart 是线性的。

## 1. 构图骨架

### 环形(最常见)

```
       ① ──→ ②
       ↑       ↓
       ④ ←── ③
```

- **节点**：3-6 个，沿圆周等角度分布
- **连线**：弧形或正交箭头，沿圆周顺时针/逆时针连接
- **闭合**：最后一个节点的箭头回到第一个节点(这是 cycle 的定义特征)

### 圆环 + 中心

```
       ① ──→ ②
       ↑  中心  ↓
       ④ ←── ③
```

中心放循环名(PDCA / 飞轮模型)，外围放步骤。

## 2. 节点规则

| 字段 | 内容 |
|---|---|
| 步骤号 | ①②③④(沿环顺时针编号) |
| 步骤名 | 动词(计划/执行/检查/改进)，≤4 字 |
| 说明 | 可选，一行 |

节点沿圆周等距分布，**同形同大**。位置用三角函数算：N 个节点，第 i 个角度 = `i × 360°/N`，坐标 = `(cx + r·cosθ, cy + r·sinθ)`。

## 3. 连线规则

- **弧线**：用 `<path>` 的圆弧 `A` 命令或贝塞尔曲线，沿环连接相邻节点
- **方向**：全部顺时针或全部逆时针，**统一**
- **闭合箭头**：最后一段连线的箭头指向第一个节点

```xml
<path d="M 600 300 A 200 200 0 0 1 800 500" fill="none" stroke="#1E3A5F" stroke-width="2.5" marker-end="url(#arrowHead)"/>
```

## 6. 红线

- ❌ 不闭合(最后一步没回到第一步 → 那是 flowchart 不是 cycle)
- ❌ 连线方向不一致(有的顺时针有的逆时针)
- ❌ 节点不等距分布(破坏循环感)
- ✅ 全部箭头方向统一(全顺时针或全逆时针)
- ✅ 步骤数 3-6 个(太少不像循环，太多看不清)
