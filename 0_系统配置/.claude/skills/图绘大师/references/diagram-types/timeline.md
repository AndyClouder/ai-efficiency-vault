# 类型：timeline(时间线 / 演进)

> 横/纵轴 + 里程碑节点。用于历史、演进、路线图、时间序列里程碑。与 flowchart 的区别：timeline 的轴是**时间**，节点是**时间点上的事件**；flowchart 的轴是逻辑顺序，节点是动作。

## 1. 构图骨架

### 横向时间轴(最常见)

```
2020        2021        2022        2023        2024
 ●───────────●───────────●───────────●───────────●
 │           │           │           │           │
[v1发布]   [v2发布]   [融资A轮]   [出海]     [上市]
 核心功能   多租户     5000万     东南亚     主板
```

- **主轴**：一条水平线(主线)，左右贯穿
- **时间刻度**：轴上等距标注年份/月份
- **里程碑节点**：轴上的圆点 + 上方/下方交替的事件卡片(避免标签重叠)

### 纵向时间轴

```
2024 ── ● [最新事件]
       │
2022 ── ● [中间事件]
       │
2020 ── ● [起始事件]
```

用于事件少但每件说明长，或移动端竖屏。

## 2. 节点规则

里程碑卡片：
- **时间**：年份/日期，加粗
- **事件名**：≤6 字
- **说明**：一行简述(可选)

上下交替排布(第1个在上、第2个在下、第3个在上…)避免拥挤。

## 3. 轴规则

- **主轴**：水平/垂直直线，2-3px，主色或中性色
- **刻度**：等距时间点，小圆点 + 年份标签
- **方向**：时间从左→右 或 从下→上(最新在上 / 起始在上，按叙事选择)

> **等距 vs 按比例**：默认等距(每个事件占一格)，视觉清晰；若时间跨度差异大且用户要"真实比例"，按实际日期算坐标(罕见)。

## 4. 分段着色

演进类时间线常分阶段(如"探索期/成长期/成熟期")，用不同色段铺在主轴背景：

```
[探索期 蓝色背景] [成长期 绿色背景] [成熟期 金色背景]
   ●──●──●           ●──●              ●──●
```

## 5. 默认画布

| 内容 | 画布 |
|---|---|
| 3-5 个里程碑横向 | 1920×720(横长条) |
| 6+ 个里程碑横向 | 1920×900 |
| 纵向 | 720×1280 |

## 7. 红线

- ❌ 不标时间刻度(读者不知道事件先后跨度)
- ❌ 事件标签全挤在轴的一侧(必须上下交替)
- ❌ 主轴方向不明(没箭头或没时间标注)
- ✅ 时间从左→右(横向)或从下→上(纵向)，方向一致
- ✅ 每个里程碑有时间 + 事件名
