# 新手引导

> 新用户的第一站。检测知识库状态 → 引导填身份 → 真实演示一条 → 交还钥匙。
> 全程亲切引导式语气，开头多一点温度，但不啰嗦。

---

## 触发条件

- 用户首次打开知识库（CLAUDE.md 启动协议检测到 USER.md 关键字段仍为"待补充"）
- 用户说："帮我上手""我是新手""怎么用""从哪开始""我不会用"
- 用户手动 `/新手引导`

---

## 工作流程

### 第 0 步：加载核心档案

读取以下文件，决定后续话术：
- `0_系统配置/SOUL.md`（获取 AI 名字、用户对 AI 的称呼）
- `0_系统配置/USER.md`（看"名字""职业/身份"等字段是否已填）

**话术基调**：按 SOUL.md 中贾维斯的人设——直白坦率、务实高效，但**开头加一句真诚欢迎**，比平时多 10% 温度。

---

### 第 1 步：检测知识库状态

扫描 5 个 PARA 目录的 .md 文件数（**排除 `1_Projects/_模板/`**）：
- `0_Inbox/`
- `1_Projects/`（排除 `_模板/`）
- `2_Areas/`
- `3_Resources/`
- `4_Archives/`

**判断逻辑**：
- **空库**：5 个目录加起来 = 0 篇 .md → 走 **第 2a 步（全新用户分支）**
- **已有内容**：≥ 1 篇 .md → 走 **第 2b 步（已有内容分支）**

---

### 第 2a 步：全新用户分支（空库）

输出：
```
👋 欢迎来到 AI 效能知识库！

我先帮你把基础信息填好，这样以后我才能真正"懂你"——
只需要 4 个问题，1 分钟搞定。
```

→ 跳到 **第 3 步（USER.md 引导填写）**

---

### 第 2b 步：已有内容分支

输出（亲切式）：
```
👋 嗨 {用户名字 / 朋友}，欢迎回来！

我刚扫了一眼，知识库里已经有 N 篇笔记啦：
  · 0_Inbox/      x 篇
  · 2_Areas/      x 篇
  · 3_Resources/  x 篇
  · ...

你想怎么开始？
```

用 AskUserQuestion 给两个选项：

| 选项 | 说明 |
|------|------|
| **[1] 保留现有内容，直接开始使用**（推荐） | 跳过初始化，直接到第 4 步看能力演示 |
| **[2] 重置知识库，从零开始** | 会先把现有内容备份到桌面 zip，再清空。适合想重新来过的用户 |

**分支处理**：
- 用户选 [1] → 直接跳到 **第 4 步（能力演示）**
- 用户选 [2] → **调用「恢复初始化」skill**
  - 等 skill 完全跑完（含备份、二次确认、清空、报告）
  - 跑完后回到 **第 2a 步**，按全新用户继续引导
  - 如果用户在恢复初始化的二次确认中反悔取消 → 询问"那我们保留现有内容，继续？"→ 跳第 4 步

---

### 第 3 步：USER.md 引导填写（核心引导动作）

用 **一次 AskUserQuestion** 同时收集 4 个核心字段（避免多轮往返，效率优先）：

```
问题：先认识一下你 ——
  Q1: 你希望我怎么称呼你？（名字/昵称）
  Q2: 你在哪个城市？
  Q3: 你的职业/身份是什么？（比如：培训师 / 产品经理 / 学生 / 创业者）
  Q4: 你主要做什么？（用一句话说说你的日常工作或主讲课程）
```

> 💡 实现技巧：用 AskUserQuestion 一次最多 4 个 question，刚好收集完。每个 question 给 2-3 个常见选项 + 用户自由输入。

**收到答案后**，用 Edit 直接更新 `0_系统配置/USER.md` 的对应字段：
- `- **名字**：（待补充）` → `- **名字**：{用户回答}`
- 同理更新 所在地 / 职业·身份 / 做什么

**其余字段**（主要收入、年度目标、受众、技术栈等）**保留"待补充"**，不强迫用户一次填完。后续 AI 会在自然对话中逐步补全。

更新后输出确认：
```
✓ 记下来啦：
  · 名字：安迪
  · 所在地：深圳
  · 职业：培训师
  · 做什么：制作高质量培训课件并授课

（其他信息以后慢慢聊就行，我会自己记。）
```

---

### 第 4 步：能力演示（标准版，含真实演示）

输出：
```
🎯 现在让你亲眼看一下，这套知识库到底能干什么。

我可以直接演示一条给你看 —— 我去搜一个真实的行业动态，
把它变成结构化笔记存进来，再自动分类。整个过程 2 分钟。

或者你想自己试一下？说一句"记一下：xxx"就行。

[1] 你先演示给我看（推荐）
[2] 我自己试试
```

#### 分支 4A：用户选"先演示" → 真实演示链路

**演示主题固定为**：**阿里巴巴近期的组织架构调整**（既贴近你 HR/组织设计专家的兴趣，又能展示完整的"搜→存→分"链路）

执行步骤：

1. **调用「网络调研」skill**，主题："阿里巴巴近期组织架构调整"
   - 真实发起 WebSearch + WebFetch
   - 落盘 1 篇综述 + 若干信源到 `0_Inbox/搜索/{今天日期}/阿里巴巴组织调整/`

2. **演示完成后**，输出通俗版总结（**不是** skill 自己的技术化报告，而是给用户看的"翻译版"）：
   ```
   🔍 演示完成！你看，整个过程是这样的：
   
   ① 你（或我）说出主题
   ② 我主动联网搜，从多个权威信源抓内容
   ③ 综合成一篇带引用的笔记，存到 Inbox
   ④ 自动归类到合适的位置
   
   你刚看到的就是一次完整的"知识入库"。
   平时你只需要说"记一下：xxx"或"调研一下 xxx"，剩下的我全包。
   ```

3. **演示收尾**：
   - 如果演示生成的笔记在 Inbox，**询问用户是否要保留**：
     - 保留 → 后续走正常分类流程
     - 删掉 → 调用 Bash 删除演示数据
   - 主动展示库当前状态（"现在你有 1 篇笔记了"）

#### 分支 4B：用户选"自己试"

把话语权交给用户，正常走「知识入库」流程。本 skill 不再介入，等用户入库完成后由知识入库 skill 自己接力。

---

### 第 5 步：收尾 + 下一步建议

输出三段式收尾：

```
✅ 初始化完成！

✓ 你的身份信息已存好
✓ 知识库已就绪
✓ 你已经看过一次完整流程了

📋 以后最常用的 5 句话（记住这 5 句就够了）：

  · "记一下 xxx"          → 存一条知识
  · "整理一下"            → 给 Inbox 里的笔记分类
  · "找关联"              → 发现笔记之间的联系
  · "看下状态"            → 看知识库仪表盘
  · "清理一下"            → 清掉过期/重复内容

💡 建议每周说一次"整理一下"+"看下状态"，知识库会越用越好用。

现在，想存点什么试试吗？
```

→ 引导结束，把控制权交还给用户。

---

## 注意事项

1. **全程亲切语气**——按 SOUL.md 贾维斯人设，但开头加一句真诚欢迎，比平时多 10% 温度
2. **USER.md 引导填写只问 4 个核心字段**——其余"待补充"，避免新用户被问烦
3. **演示必须真实执行**——真实联网搜索、真实落盘，不能"假装演示"。宁可演示慢一点，不能糊弄
4. **演示主题固定为"阿里巴巴组织架构调整"**——既贴近用户兴趣（HR/组织设计），又是时效性强的真实事件，演示效果好
5. **若用户在第 2b 步选重置**——必须等「恢复初始化」skill 完全跑完才继续；中途用户反悔则灵活回到"保留内容"分支
6. **不要过度引导**——如果用户中途说"够了，我自己摸索" → 立刻停止，给一句简短的"好的，有问题随时叫我"
7. **AskUserQuestion 一次最多 4 题**——收集 USER.md 4 字段时刚好用满，不要超
8. **全程中文输出**，技术术语首次出现给中英对照

---

## 与其他 skill 的协作

| 关联 skill | 衔接方式 |
|------------|----------|
| **恢复初始化** | 第 2b 步用户选"重置"时调用；跑完后回到第 2a 步继续引导 |
| **网络调研** | 第 4A 步演示时调用，演示"阿里巴巴组织架构调整"主题 |
| **知识入库** | 第 4B 步用户选"自己试"时，由知识入库 skill 接力处理用户输入 |
| **知识分类** | 演示落盘后，可顺带调用展示"自动归类"能力 |
| **知识仪表盘** | 第 5 步收尾时可顺带提一句"说『看下状态』随时看库情况" |
