# AI 效能知识库 · 系统配置说明

> 版本：v2.0 · 2026-07-02

## 这是什么

这是一套基于 Obsidian Vault + AI Agent 的个人知识管理系统。你不需要手动分类和整理，AI 会帮你完成。

## 三层架构

### 第一层：知识存放
所有知识以 Markdown 文件存放在 Obsidian Vault 中。支持 URL、粘贴文本、文件路径、图片任意输入格式。

### 第二层：知识整理与编译
采用 PARA + Wiki 综合层双层体系：
- **P (Projects)**：有截止日期的项目
- **A (Areas)**：持续关注的领域
- **R (Resources)**：参考资料
- **A (Archives)**：归档
- **W (5_Wiki 综合层)**：实体页/概念页/论点页/问答页——由多个来源编译出的活文档。普通笔记记录单一来源说了什么，综合页记录多个来源加起来意味着什么，随每个新来源持续修订，矛盾显式标注。这是知识库从"堆积"变为"复利"的关键层

### 第三层：知识消费
通过 10 个 AI Skill 完成知识生命周期的管理：

**知识库原生 Skill（8 个）**：
1. 新手引导 — 新用户首次使用的检测+引导+演示
2. 恢复初始化 — 备份后清空知识库，回到出厂状态
3. 知识入库 — 任意输入 → 原文保全 + 结构化笔记
4. 知识分类 — Inbox → PARA 归类
5. 知识编译 — 新来源 → 更新 5_Wiki 综合层（含交叉引用，原「知识关联」已并入）
6. 知识问答 — 基于 INDEX 定位 → 带引用作答 → 好答案回灌综合层
7. 知识体检 — 一次扫描：健康仪表盘 + 分级清理建议（原「仪表盘」+「清理」合并）
8. 配置审查 — 三方对账（注册表 × 配置说明 × 磁盘），发现偏差生成分级报告

**研究与工具 Skill（2 个）**：
9. 网络调研 — 主动联网搜索多源，综合成带引用的综述
10. 图绘大师 — 图表绘制（流程图、架构图、时间线等）

## 如何使用

### 首次使用

对 AI 说：
- "帮我上手" — 新用户引导：检测知识库状态、填写身份信息、演示能力
- 若知识库已有内容想重置："重置知识库" / "恢复初始化" — 会先备份到桌面 zip 再清空

### 存入知识
对 AI 说：
- "记一下：[内容]" — 把一段文字或 URL 存入知识库
- "存一条" — 把当前对话中的内容保存

### 整理知识
对 AI 说：
- "整理一下" — 扫描 Inbox 中的待处理笔记，AI 会逐条提出分类建议
- 确认或调整建议，AI 执行移动

### 检查状态
对 AI 说：
- "看下状态" / "体检" — 一次扫描同时给出仪表盘和分级清理建议
- "编译一下" — 把新笔记编译进 5_Wiki 综合层
- "库里怎么说 X" — 基于知识库带引用作答，好答案可回灌

## 文件结构

```
0_Inbox/           ← 新知识落点
1_Projects/        ← 项目文档
2_Areas/           ← 领域知识
3_Resources/       ← 参考资料
4_Archives/        ← 归档
0_系统配置/         ← 系统配置和记忆（不要手动改）
```

## 记忆系统

AI 会在使用过程中自动学习你的偏好：
- `SOUL.md` — AI 的性格（你来定义）
- `USER.md` — 你是谁（AI 自动更新）
- `MEMORY.md` — 长期记忆（AI 自动更新）
- `PREFERENCE.md` — 知识偏好（AI 自动更新）
- `INVENTORY.md` — 你的产品和项目（AI 自动更新）
- `DASHBOARD.md` — 知识库数据（AI 自动更新）

## 兼容性

- 同时支持 Claude Code 和 Codex 两个 AI Agent
- Skill 在四处目录镜像存放，**内容必须完全一致**：

| 目录 | 角色 | 谁读取 |
|------|------|--------|
| `0_系统配置/.agents/skills/` | **Codex 配置源**（注册表登记的真身） | 作为同步基准，不被 Agent 直接加载 |
| `0_系统配置/.claude/skills/` | **Claude 配置源**（注册表登记的真身） | 作为同步基准，不被 Agent 直接加载 |
| `.agents/skills/` | Codex 运行时副本 | Codex CLI 运行时加载 |
| `.claude/skills/` | Claude Code 运行时副本 | Claude Code CLI 运行时加载 |

- **新增/修改 skill 时，四处必须同步更新**（用 `cp -r` 复制后做 MD5 校验）
- 当前已对齐的 10 个 skill：图绘大师、新手引导、恢复初始化、知识入库、知识分类、知识编译、知识问答、知识体检、网络调研、配置审查
