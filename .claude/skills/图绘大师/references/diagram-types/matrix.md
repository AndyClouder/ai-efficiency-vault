# 类型：matrix(矩阵 / 四象限)

> 2×2 或 3×3 网格，两轴有标签。用于 SWOT、BCG、四象限分析、Ansoff、Eisenhower 等二维分析框架。

## 1. 构图骨架

2×2 四象限(最常见)：
```
            轴Y(高)
              ↑
         ┌────┬────┐
         │ Q1 │ Q2 │
   ← ────┼────┼────┼────→ 轴X(高)
         │ Q3 │ Q4 │
         └────┴────┘
              ↓
           轴Y(低)        轴X(低)
```

- **网格**：等大格子(2×2 或 3×3)，细线分隔
- **轴**：横轴(X)和纵轴(Y)各有一个语义标签(如"重要性" / "紧急度"，或"收益" / "成本")
- **轴端**：两端标"高"/"低"或具体语义("重要"/"不重要")
- **格内**：每个象限一个标题 + 要点列表

## 2. 象限规则

每个象限：
- **象限名**(如 SWOT 的"优势/劣势/机会/威胁")，顶部，加粗
- **内容**：2-4 个要点(短句或词组)，可带项目符号

象限可用不同浅色底区分(SWOT：优势绿、劣势红、机会蓝、威胁橙)，但都在 spec_lock 色系内。

## 3. 轴标签规则

轴标签是 matrix 的灵魂——没有轴标签的 2×2 只是四个格子：

- **横轴**：底部居中，标语义(如"影响程度")，两端标"低 ← → 高"
- **纵轴**：左侧竖排或旋转，标语义(如"发生概率")，两端标"低 ↑ 高"

```xml
<text x="640" y="690" text-anchor="middle" font-size="14" font-weight="700" fill="#0F172A">影响程度 →</text>
<text x="30" y="360" text-anchor="middle" font-size="14" font-weight="700" fill="#0F172A" transform="rotate(-90 30 360)">发生概率 →</text>
```

## 6. 红线

- ❌ 不画无轴标签的矩阵(失去分析意义)
- ❌ 象限不等大(破坏比较基准)
- ❌ 象限内容过多(每格 2-4 点，过多则拥挤)
- ✅ 横纵轴语义清晰，高低方向明确
