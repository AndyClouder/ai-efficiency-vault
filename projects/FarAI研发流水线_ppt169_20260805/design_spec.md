### P21 · Harness 先行原则 ★价值闭环呼应
- **layout**:breathing,左右对比
- **rhythm**:breathing
- **title**:先建 Harness 再放 Agent,顺序错了全是反模式
- **core message**:Harness 先行,Agent 在 Harness 内跑;先放 Agent 再补 Harness = 不可控
- **content**(左右对比):
  - 左 ✅(正确顺序):
    - 01 Harness 先建(CLI/fullcheck/E2E/hooks)
    - 02 Agent 在 Harness 内跑 Loop/Graph
    - 03 Agent feedback 反哺 Harness 持续强化
  - 右 ❌(反模式):
    - **Loop Engineering**:先让 Agent 跑循环再补约束 → 失控
    - **Graph Engineering**:先让 Agent 跑任务图再补治理 → 失控
    - 共性:顺序错了,后期补 Harness 成本极高,且事故已发生
- 底部巨型结论:**先建安全网,再放大自主度**
